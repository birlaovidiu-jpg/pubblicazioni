# Dipartimento di Pubblicazioni

Programma del Dipartimento di Pubblicazioni — Chiesa Avventista del 7° Giorno, Movimento di Riforma, Campo Italiano.

Si usa da qui: **https://birlaovidiu-jpg.github.io/pubblicazioni/**

- `index.html` — il programma (un file solo, funziona anche senza internet)
- `sw.js` — il guardiano per l'uso senza internet

I dati (libri, abbonati, movimenti) restano nel dispositivo di chi lo usa: non sono in questo sito.
Per portarli da un dispositivo all'altro si usa il backup (Dati e backup).
